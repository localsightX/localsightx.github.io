Capabilities

Everything runs on your hardware

Reference implementations work out of the box; drop in a staged ONNX / TensorRT / OpenVINO / TFLite model via the ModelRegistry for production accuracy. There are no insecure defaults and no third-party calls.

🎯

Multi-class object detection

A SORT-style tracker produces stable IDs. The onnx backend detects person / vehicle / bicycle / motorcycle / bus / truck / animal / bag / package with GPU auto-detection; the reference CPU fallback handles demos without a model.

🔢

ANPR / LPR

Cropped, throttled and de-duplicated plate pipeline. Plate values are encrypted at rest with an anonymized hash. Real OCR activates when you stage a plate detector + OCR model.

🪪

Face identification opt-in

Biometric matching is off by default. Enable only with a documented lawful basis; enrollment embeddings are encrypted and retention-bounded.

⚡

Behavior analytics

Per-camera JSON rules: line_cross (directional), intrusion, loitering, object_left, crowd. Matched events become typed alerts fanned out to your channels.

📡

Live view (LL-HLS)

Ticketed, authorized low-latency HLS gateway transcodes the substream with FFmpeg. RTSP URLs and credentials are never exposed. Health endpoint shows active transcodes and PIDs.

📤

Event clip export

Pull a signed, time-stamped manifest of every VideoSegment overlapping an event — for evidence handoff, insurance claims, or incident review. All downloads are audit-logged.

📊

Analytics & BI

People counting, occupancy trends, dwell time, event-type breakdown, heatmaps and a unified timeline — all behind analytics:view and ready for your dashboards.

🔎

VLM semantic search

Ask in natural language — "find the red truck near the gate" — and rank archived events by similarity. A CLIP / VLM backend drops in behind the same interface.

📨

Multi-channel alerts

Route events to webhook, email, MQTT, or push (ntfy.sh). Per-route cooldown_sec suppresses storms; SSRF-validated webhooks; a test endpoint verifies delivery.

🛡️

Hardened by default

Argon2id passwords, JWT rotation, TOTP MFA, RBAC, envelope encryption, signed media URLs and an immutable audit log of every sensitive action.

How it works

From RTSP stream to actionable alert

LocalSight is a focused pipeline: AI runs on the low-res substream while the main stream is recorded, keeping bandwidth and compute minimal. Every step is local, encrypted, and auditable.

  1. 1

    Ingest

    Pull RTSP / RTSPS / ONVIF streams from cameras and NVRs. TP-Link VIGI/Tapo NVRs provision in one call; ONVIF discovery and multi-vendor presets (Axis, Hanwha, Hikvision, Dahua, Reolink, Bosch, GB/T 28181) cover the rest.

  2. 2

    Analyze

    The worker runs local multi-class detection, tracking, behavior rules, ANPR and (optional) face matching on the substream — no frames leave the server. GPU acceleration is automatic when an ONNX model is staged.

  3. 3

    Record & store

    Main-stream segments are written to local or S3 storage; snapshots, embeddings and plates are encrypted at rest. The unified timeline merges events and recording for fast review.

  4. 4

    Act & review

    Matched events trigger routed alerts (webhook / email / MQTT / push), populate analytics, and become searchable via timeline + VLM semantic search. Event clip export delivers signed evidence bundles.

Privacy & compliance

Built so video stays yours

  • No cloud by default. All inference is local; the platform makes no outbound calls to third parties.
  • Recognition is opt-in. Face identification is disabled unless you explicitly enable it with a lawful basis.
  • Encrypted at rest. Stream URLs, embeddings, snapshots, plate data, alert configs, and MQTT credentials use envelope encryption (AES-256-GCM, per-record data keys).
  • SSRF guard. Camera, webhook, and ONVIF egress are blocked to private / loopback / metadata destinations unless allow-listed.
  • Per-route alert cooldown. Suppresses alert storms — one page per (channel × rule × camera) per window.
  • Immutable audit log. Every sensitive action — camera changes, alert routes, live-ticket issuance, video clip exports — is recorded.
  • Bounded retention. A worker sweeper auto-expires recordings, events, snapshots, and embeddings on schedules you control.
  • Free supply-chain security. The CI pipeline catches vulnerable deps and SAST issues using only free-tier tools (pip-audit, Safety, Trivy, CodeQL, Semgrep).

Quick start

Running in minutes

LocalSight refuses to start if secrets are missing — there are no insecure defaults.

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/gen_env.py        # writes .env with fresh random secrets

uvicorn apps.api.main:app --host 0.0.0.0 --port 8000 --reload
# dashboard served at http://localhost:8000

# in another shell — runs cameras, recording, retention + alerts
python -m apps.worker
python scripts/gen_env.py
docker compose -f infrastructure/compose/docker-compose.yml --env-file .env up --build
# brings up PostgreSQL+pgvector, the API, the AI worker and an nginx TLS proxy

Recording and live view require FFmpeg on PATH (bundled in the Docker image). The default DB is SQLite; set DATABASE_URL for PostgreSQL.
